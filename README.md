# Serico 个人主页

这是 Serico 的中英双语个人主页。读者主要是做外贸、做企业、想用 AI 提效、自己不写代码的老板：看完应当带走一套完整的思路（哪些活值得交给机器、怎么挑第一步、人留在哪、哪些事不交给 AI），并记住 Serico 这个名字。页面只讲思路，不讲做法：工具名、模型名、提示词、系统怎么搭、怎么维护，一个字都不写；站主现在没有对外的落地项目，也不能写得像在接单。仓库里已有可运行的 Astro 静态站，可以直接在现有页面上调整设计。[English](https://serico.ai/) · [中文首页](https://serico.ai/zh/) · [源码仓库](https://github.com/bestduijin/bestduijin.github.io)

## 视觉与阅读体验

设计从名字里的「丝」取材，整页是同一片夜（2026-11-25 起固定深色，不再跟随系统的浅色）。颜色都取自首屏的画，定义在 [global.css](src/styles/global.css)：底色夜空 `#070b1a`（首屏底边是 `#070c20`，下面从这个颜色渐到底色，接缝看不出来），大字暖白 `#f3f0ea`，正文雾灰 `#cdd0e0`，小字 `#8b91ad`；丝带的粉 `#ea91a8` → 金 `#e8c488` → 青 `#74d4c9` 只用在四处：丝线、四步序号的悬停、分工表里当前行（和悬停那一行）的序号和左边短线、最后的 serico。新加的段落只靠字号、细线和留白，没有配图、色块和卡片；编号只有两处：四步（01–04）和五道工序（01–05）。

字体：大字（标题、步骤名、自述、四个词）用 Bodoni Moda，中文大字用设备上的宋体；首屏以下的正文和小字用 Jost，中文正文用设备上的黑体（苹方等）。正文字号：英文 19–20px（Jost 字身矮，这样读起来相当于常见无衬线的 18px）、中文 17–18px，行宽英文约 60–75 个字符、中文约 30–38 字（三件事分三栏时一行短一些）；分工表格子英文 18px、中文 17px；表头、「仅作演示」、词源下面的小字等附注 15px 左右。两种西文字体都通过 Fontsource 打包、随站点加载，许可都是 SIL Open Font License 1.1，版本在 `package.json` 里写死。中文大字（大标题、各段的小标题）先按标点断行，一句放不下再在词与词之间换行（构建时用 `Intl.Segmenter` 分词），不会把「经验」「东西」拆开；短段落用 `text-wrap: balance`。正文每段最后几个词连在一起不拆（中文至少 4 个字、英文 2 个词，`Page.astro` 的 `para`），不会有一两个字或一个词单独掉一行。

**丝线**是首屏以下唯一的滚动动效（[src/scripts/silk.ts](src/scripts/silk.ts)）：一根细线从首屏底缘渐显出来，几道从容的大弧往下走——沿右边页边落下，在「现在在做」和名字那一段之间横着摆过整个页面（从丝带画上方经过）；「三件事」的大标题左边要么不走，要么只走页边外侧三分之一（1280 宽及以上，找路时离这行字留 58px，`silk.ts` 的 `PAD.wide`；2026-11-26 起，1440 宽也因此改成这条走法，原来是在演示视频和「三件事」之间横摆、贴着这行大标题左边落下）；然后从名字左边落下，最后一道整圆弧（半径最大 160px）顺势落进四个词上方的线，停在 serico（四个词竖排时，它从上面直接落到第一个词，顺着竖线往下）。走法不是写死的：打开页面时等字体就绪（`document.fonts.ready`，最多等 1.5 秒，字体一直不来也照样画）找一次，之后只有窗口宽度变了（或晚到的字体把页面挪动了）才重新找；只改高度（手机工具栏伸缩）不重新找路，只重算画的进度。找路之前只有四个词之间那条静态细线（和没有脚本时一样），线一出现就在最终位置，不会先有后无或跳一下。脚本按页面上文字、视频、按钮的真实位置，在一张粗网格上找一条「弯得少、尽量走在空处」的路线；线本身只取这条路线上的少数几个点（1440 宽约 10 个，相隔约 380px），用向心 Catmull-Rom 拟合成一整条平滑曲线。曲线离东西太近时，整点挪开或补点后整条重新拟合；拐得太急（曲率半径不到 80px）时，去掉或挪动附近的点再整条重新拟合，从不逐点修。净空：离大标题和自述至少 40px（768 宽时页边只有 46px，放宽到 28px），离其他文字 20px、按钮 24px、视频、四步列表和分工表 16px，离屏幕边 12–20px；分栏的段落（情形、三件事、现在在做）整段不穿（不从栏缝里走）。为了让线能从容地横摆过去，「三件事」和名字那一段前面的段间距加大到约 1.5 倍（13–15rem）。找路加拟合一次 40–350ms（820 宽的中文页约 0.65 秒），窗口拖动时等停下来才重算。页边窄到走不出来时（手机），只画四个词旁边那条竖线；768 宽中英文、820 宽中文是完整的线；820 宽英文（演示段大标题几乎占满一行，两边留不出净空）和 834、900、960、1112 宽找不到路，也只画那条线。`.night` 上的 `data-silk` 写着这次是完整的还是只画了线、用了几个点、最急的弯多大、花了多少毫秒，`data-silk-runs` 是打开以来找了几次路。画的进度跟着屏幕走：线画到哪，大致就在屏幕从上往下 75% 的位置；四个词上方那条线进入这个位置就开始画，再滚大约三分之一屏画完。开了「减少动态效果」时整根直接显示；没有脚本时四个词之间有一条静态细线（CSS），内容照样都在。除了丝线、首屏的光、演示视频和跟着视频亮起的那一行，页面上别的东西都不动。

两幅画在 `public/art/`：`band.webp`（「名字」背后的丝带，手机用 `band_tall.webp`，现在还是从首屏的画裁出来顶着的）、`ending.webp`（页尾的沙丘远城，手机用 `ending_tall.webp`，2026-11-26 换成了专门画的新图，原图在 `B003/个人主页_插画/drafts/ending_b.png`、`ending_tall_a.png`；原来的首屏裁图备份在 `B003/个人主页_改版/备用图/`）。换画只换这些文件，页面只认文件名，四边用遮罩融进底色；换画以后要重新确认压在画上的字对比度够（≥ 4.5:1）。

首屏插画在 `public/hero/`：`hero_wide.webp`（宽屏）、`hero_tall.webp`（宽高比小于 3:4 的手机），是用 Codex 订阅出的图，提示词和草稿在 `B003/个人主页_插画/`。上面的光是 [src/scripts/sky.ts](src/scripts/sky.ts) 用 canvas 画的，丝带、驼队、城市的位置是照两张画描的坐标，**换了画就要重描**。

### 首屏的驼队动画

首屏画上沙脊那一队骆驼会走（[src/scripts/caravan.ts](src/scripts/caravan.ts)，和天上的光画在同一块 canvas、同一个动画循环里）：沿着画里那条金色的路，来回拐着走到右边远处的城，越远越小、越淡，最后只剩几点灯火融进城里；第一队走到大约七成时，左边沙脊背后先亮起一片暖光、沙脊勾出一道金边、几颗灯火往上飘，接着一支更气派的队伍（13 头，有疏有密）翻上沙脊，领头的驮货上飘起一条长长的丝带（玫瑰金，尾梢带青，和天上的丝带同一种颜色），走过的那段路会亮一会儿再慢慢暗回去；之后普通的、气派的轮流接上，一直循环。第一队约 43 秒到城，第二队约 28 秒出场。

- **怎么做的**：画上原来的驼队不动，动画开始的头 0.8 秒，在原位置盖一小块「没有骆驼的沙丘」补丁（另一块补丁抹掉路上那串很小的静止骆驼），换成程序画的骆驼：骆驼的身子就是从画上抠下来的那几头，只有腿是程序按骆驼的步态（同侧两条腿一起迈）画的。路线、补丁、前面挡住路的那一小块沙丘，都按图片像素存，页面按图片实际铺放的位置换算（和 `sky.ts` 一样是 `object-fit: cover`）。
- **什么时候不动**：没有脚本、开了「减少动态效果」、点了暂停、滚出首屏、标签页不在前台时，驼队和流光一起停（或一起不出现）；没出现时看到的就是原画，驼队在原位。暂停后再播放，从停下的地方接着走；暂停时改窗口大小，画布按停下那一刻重画一帧，不会退回原画。
- **避开字**：每次字体加载完、窗口大小变了、语言提示出现或关掉，`Page.astro` 都重新量一遍首屏上字和按钮的位置（换算成 canvas 上的位置，首屏缓慢推近的两头都算进去）。路要是从字底下过，新一队就改在字后面那段沙脊、从沙脊背后升上来；要是连画上原来那队站的地方都压着字，就不走、保持原画。丝带靠近字会整条淡下去。`.hero` 上的 `data-caravan` 写着这次是 `walks` 还是 `stays`。
- **手机竖屏（`hero_tall.webp`）不走**：驼队在那里很小，压在大标题正下方很深的暗色里，保持原画；驼队的图也不下载（只有确定要走时才加载）。
- **首屏推近**：`Page.astro` 里 `.drift` 的 `--drift-from`、`--drift-to`、`--drift-x`、`--drift-y` 和 `transform-origin` 是唯一的出处，`@keyframes drift` 和驼队都从这里读（驼队要在推近把它裁掉之前化成灯火）。改推近只改这几个数。
- **素材**：图在 `public/hero/caravan/`（骆驼身子 `bodies.webp`、补丁 `patch_*.webp`、前面那块沙丘 `occ_*.webp`，一共约 30 KB），数据在 `src/scripts/caravan/`（`route.json` 路线、`bodies.json` 每头骆驼的脚底、腿、灯笼位置、`patch.json` 补丁位置）。
- **换了首屏的画以后**：在 `B003/个人主页_插画/驼队动画/` 里按顺序重跑 `make_patch.py`（补丁）、`make_route.py`（路线和前面的沙丘；路线上的点要照新画重标）、`make_bodies.py`（骆驼身子；灯笼位置是手量的，要重量），用 `B003/.venv-tts/bin/python`；再把 `assets/` 里对应的文件拷进上面两个文件夹。那个文件夹里还有 `样片.html` 和出证据的脚本。

首屏以下第三段的演示视频在 `public/cover/`（中英各一条横版，约 0.7 MB，配一张封面图），是用代码做的：画面在 `B003/讲解视频/主页封面_自动化大屏/ui/screen.html`，在那个文件夹里跑 `python3 make_cover.py` 出片，`--publish` 拷进本仓库。

首屏的光和演示视频都有暂停按钮（WCAG 2.2.2），只在滚到眼前时才动；开了「减少动态效果」就不自动动，访客自己点「播放」才动。原来的丝带 [Ribbon.astro](src/components/Ribbon.astro) 现在没用上，留着备用。

## 在本地打开

准备 Git、Node.js（项目声明最低版本为 22.23.4）和 npm。首次接手时运行：

```bash
git clone https://github.com/bestduijin/bestduijin.github.io.git
cd bestduijin.github.io
npm ci
npm run dev
```

打开终端显示的地址，默认是 `http://localhost:4321/`。首页是英文版，直接访问 `/zh/` 可以检查中文版。要看语言提示，把浏览器的首选语言调成中文再打开 `/`；看过一次又关掉了的，在开发者工具里删掉 `localStorage` 的 `serico:lang-hint`。交付前按 Ctrl+C 停止开发服务，再预览实际要发布的版本：

```bash
npm run build
npm run preview
```

构建成功后，`dist/index.html` 和 `dist/zh/index.html` 分别对应英文和中文首页，`dist/en/index.html` 是 Astro 生成的跳转页（跳到 `/`）。

## 交付时怎么验收

在生产预览里逐项检查。键盘、页面语言和放大阅读的检查方法可参考 [W3C WAI Easy Checks](https://www.w3.org/WAI/test-evaluate/easy-checks/)。

- [ ] 直接打开和刷新两个语言地址都能读到完整内容。点击「中文」进入中文页，点击「English」回到英文页。打开旧地址 `/en/` 会到 `/`。
- [ ] 浏览器首选中文时打开 `/`，右上角语言链接下面出中文提示，不挡字标；点关闭后刷新不再出现。浏览器首选英文时打开 `/` 不出提示。
- [ ] 在手机宽度下读完开场自述和四个词源，文字没有被裁切。桌面浏览器放大到 200% 后，正文和链接仍可读、可用。
- [ ] 只用 Tab 和 Enter 就能切换语言、走到分工表的五个工序名并让视频跳过去，并能看清当前焦点。
- [ ] 演示视频播到哪道工序，分工表亮哪一行；点第 4 行，视频落在第 9 秒（第 4 道开头），原来在播就接着播、暂停就还停着。开「减少动态效果」刷新，表是普通的静态表。
- [ ] 首屏三个数字各点一次（也用 Tab 走到再回车），分别到「情形」「四步思路」「演示视频」，前两段大标题上面留着空、不贴顶，演示那段大标题和视频一起进屏幕。
- [ ] 页面和生成的 HTML 里搜不到 `bestduijin`、`foreign trade`、「科班」「读作」`Say it`、`trained programmer`。
- [ ] 切换系统深浅色，页面都是深色，正文与链接清晰可辨。首屏的字压在插画上仍然看得清；往下滚，丝线跟着画出来，不压任何字、视频和按钮，最后停在 serico；首屏和演示视频各点一次「暂停」都会停、按钮变「播放」。开启「减少动态效果」并刷新，两处都不自己动。
- [ ] 查看生成的 HTML，中文页的 `lang` 为 `zh-Hans`，英文页为 `en`；两页的描述使用各自语言，canonical 链接指向各自的正式地址，`x-default` 指向英文 `/`，`og:locale` 分别是 `en_US`、`zh_CN`。

## 发布到 GitHub Pages

仓库的发布流程监听 `main`。首次配置时，在 **Settings → Pages → Build and deployment → Source** 选择 **GitHub Actions**。改动合入 `main` 后，在 **Actions → Deploy to GitHub Pages** 查看构建与部署结果；成功后打开页首的两个正式地址复查。本站用自己的域名 `serico.ai`（在 Cloudflare 买的，DNS 也在 Cloudflare），在仓库 **Settings → Pages → Custom domain** 里填；用 GitHub Actions 发布时不需要 `CNAME` 文件。Astro 的 `site` 已配置为 `https://serico.ai`。DNS 怎么配见 [GitHub 官方：管理自定义域名](https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site/managing-a-custom-domain-for-your-github-pages-site)。[仓库发布流程](.github/workflows/deploy.yml) · [Astro 官方部署指南](https://docs.astro.build/en/guides/deploy/github/)
